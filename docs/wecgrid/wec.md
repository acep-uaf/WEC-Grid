# WEC Module

This module contains the Wave Energy Converter (WEC) device and farm abstractions used in WEC-Grid.

## Overview

The WEC module provides:
- **WECDevice**: Individual wave energy converter device modeling
- **WECFarm**: Collection and management of multiple WEC devices
- **WECSimRunner**: Integration with WEC-Sim simulation engine
